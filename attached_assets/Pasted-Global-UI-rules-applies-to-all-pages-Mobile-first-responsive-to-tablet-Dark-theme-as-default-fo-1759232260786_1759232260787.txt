Global UI rules (applies to all pages)

Mobile-first, responsive to tablet. Dark theme as default for /funds and optional dark mode globally.

All timestamps in IST, full format: Sep 30, 2025 — 14:32 IST.

Accessibility: ARIA labels, large-tap targets, color-blind safe palette (P&L green/red + pattern indicators), text scaling.

Live updates: market and vendor prices should update on the UI every 1 second in dev/demo using a simulation stream; production uses real market feeds with throttling.

Vendor-aware: vendor logo + verification badge displayed whenever vendor-specific pricing applies.

Persistence: sticky hero on top of /investment with From / To account selectors and right-side actions (Add funds + AI-Invest button).

All important actions must show confirmations and final permission flows before executing money-moving operations.

Live dummy data & 1-second updates (how-to implement for dev/test)

Goal: make UI feel realistic with data changing every 1 second for demo mode.

Recommended approach:

Demo-backend stream: a lightweight websocket endpoint /ws/demo-prices that emits JSON ticks every 1 second for all visible instruments (stocks + vendor prices). In production, this would be replaced with real market feed + throttling.

Front-end fallback: if websocket unavailable, front-end runs a timer setInterval(1000ms) to update UI using small pseudo-random fluctuations around last price (e.g., ±0.1% per tick) and drives sparklines.
