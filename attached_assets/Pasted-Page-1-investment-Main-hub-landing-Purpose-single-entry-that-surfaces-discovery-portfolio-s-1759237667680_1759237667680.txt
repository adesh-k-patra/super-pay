Page 1 — /investment (Main hub / landing)
Purpose: single entry that surfaces discovery, portfolio snapshot, quick access to core tabs.
Top UI / layout
* Persistent header: Search (typeahead), Notifications bell, Profile.
* Sticky Hero card (left → right):
    * Total Portfolio Value (₹) — large
    * Today P&L (₹ & %) + 1s-updating sparkline
    * From Account selector (dropdown with masked last 4)
    * To Account selector (Vault / Broker / Physical)
    * Buttons: Add Funds (primary) | AI-Invest (secondary)
* Tabs row: Explore | My Investments | Orders | Watchlist | AI-Invest | Stats
* Below hero: horizontally-scrollable cards:
    * Quick Market Ticker (NSE/BSE + commodity quick cards)
    * AI-recommendations (3 cards) with Apply and Save
    * Recent activity (last 3 orders)
Data & KPIs
* total_invested, current_value, unrealized_pnl (₹ & %), today_pnl, cash_balance, unsettled_amount, XIRR_since_first_trade
Primary actions
* Tap tab → corresponding page
* Quick Buy from hero → unified Buy modal
* Set price alert → opens alert creation flow
Backend / Integrations
* /api/portfolio/summary (GET)
* Websocket /ws/portfolio/updates
* AI recommendations /api/ai/recommendations
Acceptance criteria
* Hero updates within 2s of relevant data change; toggling From Account updates checkout defaults.

Page 2 — Explore (category discovery + vendor compare)
Purpose: discover assets and compare vendor offers.
Top UI
* Search (global) + Filters bar: Category, Vendor, Risk, Min investment, Delivery type, Sort
* Category tiles (grid/horizontal): Precious Metals | Stones | Stocks | Mutual Funds | ETFs | Bonds | Others
Within category (e.g., Gold)
* Vendor Offer Cards list:
    * vendor_logo + verified_badge
    * price_per_unit (₹/g), spread, last_updated (Sep 30, 2025 — 14:32 IST)
    * delivery_type (Digital/Physical), min_qty, rating
    * CTAs: View | Buy | Compare checkbox
* Compare mode:
    * up to 3 vendor offers side-by-side
    * columns: price, fees, min_qty, buyback_terms, vault_fee, delivery_days, certification
    * actions: Select & Buy / Auto-route
Data fields
* Offer timestamp, inventory_count, buyback_percent, vault_fee_annual, insurance_included_bool
Primary actions & flows
* View → Asset Detail (vendor-scoped)
* Compare → Compare modal
* Buy → opens Buy modal prefilled with vendor & defaults
Backend
* /api/vendor/offers?asset=gold (GET)
* /api/vendor/compare (POST)
* price feed ingestion & caching /ingest/vendorprice
Acceptance criteria
* Filters respond under 300ms for typical response sets; compare modal shows all fees computed for 3 vendors.

Page 3 — Asset Detail (vendor-aware pre-buy)
Purpose: single-pane of truth for asset + vendor before buy.
Top UI
* Header: Asset name — Vendor + live price + 24h change + market status badge
* Vendor Offer Card (expanded): price/unit, last_updated, min_qty, fees (line items), delivery options, buyback_terms, certifications
* Interactive chart: 1D/1W/1M/3M/1Y/Max; overlay other vendor prices or benchmark
* KPI row (varies by asset class):
    * Stocks: Last price, Day change, Market Cap, P/E, EPS, 52W high/low, Avg vol, Dividend yield, Sector
    * Mutual Funds: NAV, 1D chg, AUM, Expense ratio, Riskometer, Fund manager, Inception date, trailing returns table
    * Metals: Purity, price/gram, vault_fee, insurance, redemption_fee
    * Diamonds: Carat, cut, clarity, color, certificate (GIA/IGI), buyback_estimate
* Seller profile: rating, verification badges, SLA, contact
* Related instruments & AI says X% allocation badge
Buttons
* Buy (this vendor) (primary) | Compare vendors | Add to Watchlist | Set Alert | Share
Flows
* Buy opens unified Buy modal with vendor preselected
* Compare vendors launches compare tray
* Set Alert → alert creation flow (price / % change / spread)
Backend
* /api/asset/{asset_id}/detail?vendor={vendor_id} (GET)
* /api/chart/ohlcv?asset=...&range=1M (GET)
* vendor profile /api/vendor/{vendor_id} (GET)
Acceptance criteria
* Chart loads within 500ms for 1M timeframe; vendor fees are visible and calculable.

* Limit & Stop fields shown only when relevant
* Slippage tolerance control (0.1%–5% or absolute ₹)

* Preview estimate block (line-items): Qty, Price/unit, Brokerage, Vendor fee, GST, Shipping (if any), Total payable
