Page 5 — My Investments (Holdings)
Purpose: consolidated portfolio with per-asset vendor & performance detail.
Top UI
* Portfolio snapshot: Total Invested | Current Value | Unrealized P/L (₹, %) | Today P/L
* Allocation donut / bar: by asset class & vendor (tap segments to filter holdings)
* Tabs: All holdings | By Asset Class | By Vendor
Holding row
* Asset name + vendor chip
* Qty/Units | Avg buy price | Last price | Current value | Unrealized P/L (₹ & %)
* % allocation of portfolio
* Quick actions: Buy | Sell | Move custody | More (three-dot)
Holding detail (tap)
* Transaction history: chronological buys/sells with Order ID & UPI txn id
* KPIs: XIRR, CAGR, Holding period, Weighted avg buy price
* Vendor certificate & link to verify
* Options: Request physical delivery (metals/diamond) — open flow with KYC checklist + shipping estimate + fees
* Buttons: Sell | Buy more | Move custody | Export CSV | Set alerts | Lock for tax-report
Special features
* Move custody flow: transfer between vault / broker custody / physical (requires API to custody provider)
* Start SIP available for funds only (button visible)
* Holding-level notes (user can add custom note)
Backend
* /api/portfolio/holdings (GET)
* /api/transactions?asset_id=... (GET)
* custody transfer /api/custody/transfer (POST)
Acceptance criteria
* Holding detail shows XIRR computed consistently with portfolio engine; export CSV works for heavy portfolios up to 10k rows.

Page 6 — Orders (All transactional states)
Purpose: track all buy/sell & vendor interactions.
Top UI
* Tabs: Active | Executed | Cancelled | Partial | Failed | Settlements
* Global search + filter by asset/vendor/date/status
Order row
* Asset + Vendor | Buy/Sell | Qty | Order Type | Price | Status pill (color coded) | Timestamp
* Quick actions on row: Cancel (if cancellable) | Retry (failed) | Dispute (failed or delivered incorrectly)
Order detail
* Timeline: Created → Submitted → Vendor Confirmed → Matched → Fills (if partial, list each fill) → Executed → Settled
* Execution details: executed_price(s), execution_qty(s), brokerage & fees breakdown, taxes, UPI txn id, settlement_date/time
* Vendor-specific steps (if marketplace): vendor confirmation time, delivery tracking or vault lock id
* Buttons: Cancel order (if allowed) | Raise dispute | Download receipt (PDF)
Flows
* Auto-notify user if vendor needs to accept; show Vendor confirmation required modal
* For failed orders: provide Retry and Manual payment reconciliation options
Backend
* /api/orders (GET) with params
* /api/orders/{order_id}/timeline (GET)
* cancellation endpoint /api/orders/{id}/cancel (POST)
Acceptance criteria
* Order timeline is consistent and filled with accurate timestamps and UPI txn id when applicable.

Page 10 — Commodities & Precious Metals (Gold, Silver, Platinum, Bronze)
Purpose: vendor marketplace for metals — buy digital or request physical.
Category listing
* Vendor Offer Cards with price/gram, purity, vault/storage fee, min buy, buyback guarantee, delivery options
Asset Detail
* Purity, price/gram, last updated timestamp, vault fee, insurance, redeem fee, min qty
* Chart overlay: LBMA or global benchmark vs vendor prices
* Delivery choices: Buy Digital (Vault) or Request Physical Delivery — each shows fees & timeline
Buy flows
* Digital: buy → stored in vault → view in Portfolio under custody Vault
* Physical: buy → triggers escrow hold until delivery confirmation → KYC & shipping flow
Delivery flow
* User requests delivery → show KYC checklist, address verification, shipping charges, ETA, allow pickup at vendor store (if supported)
* On delivery, vendor updates status to Dispatched → user can confirm & release escrow
Backend
* vault provider API /api/vault (lock/unlock/listings)
* escrow /api/escrow (POST)
* vendor inventory & lock /api/vendor/lock
Acceptance criteria
* Digital buys reflect in vault within 2–10 minutes depending on vendor; physical request starts KYC flow immediately with clear fees.
