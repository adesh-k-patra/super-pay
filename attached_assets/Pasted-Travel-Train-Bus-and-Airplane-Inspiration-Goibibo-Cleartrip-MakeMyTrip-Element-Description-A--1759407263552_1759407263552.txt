Travel: Train, Bus, and Airplane

Inspiration: Goibibo, Cleartrip, MakeMyTrip
Element	Description
A. Section Overview	Goal: A single, transparent platform for multimodal travel booking. Key Differentiators: Integrated fare-comparison across all modes, PNR/Live Status tracking (especially for Train).
B. Core Feature Set	1. Unified Search: Single search bar for City/Airport/Station (e.g., Delhi → Mumbai). 2. Real-Time Data Feeds: Live seat/ticket inventory from GDS/IRCTC/Bus operators. 3. Manage Booking: Self-service modification, cancellation, and rebooking.

D. Page-Wise Blueprint	Search Page: One-way/Round trip toggle, Date Picker, Class/Passenger dropdown. Results Page: Tabbed view for Flight/Train/Bus, Price/Duration sort options, Promo banner. Passenger Details Page: Traveler info entry, Loyalty/GST input. Manage Booking Page: List of upcoming/past trips, dedicated action buttons (Modify/Cancel/Check-in).
